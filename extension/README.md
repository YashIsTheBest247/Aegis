# Aegis AI — Chrome Extension

Load the extension locally:

1. Make sure the Aegis backend is running on **http://localhost:8010**.
2. Open **chrome://extensions** → enable Developer Mode.
3. Click **Load unpacked** and select this `extension/` folder.
4. The Aegis shield icon appears in your toolbar.

**How to use:**
- **Right-click** any selected text or link on a webpage → "Aegis AI → Scan this for scams" → desktop notification shows the verdict.
- **Click the toolbar icon** to open the popup and paste a message to scan.

> Icons (`icon16.png`, `icon48.png`, `icon128.png`) are placeholders — swap in any Aegis-branded PNGs.
