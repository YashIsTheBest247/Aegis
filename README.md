# Aegis AI — The AI Shield That Beats AI Scams

> **ForgeHacks 2026 · Track: AI + Cybersecurity**
>
> _"Build an AI-powered solution that helps people recognize, prevent, verify, or respond to scams, impersonation, and fraud enabled by AI or modern technologies."_

Aegis AI is an open-source, **Gemini-powered defense system** that detects phishing, voice-clone fraud, deepfake text, screenshot scams, and impersonation attacks **in real time** — so grandparents, employees, and everyday people never fall for the next AI-powered trick.

---

## 🎯 Problem Statement

In 2026, scams cost people **$4.6 trillion globally**. The reason it's exploding is **AI**:

- **Deepfake fraud grew 3000% YoY.** Scammers clone a grandchild's voice from a 3-second TikTok clip and call grandma asking for bail money.
- **AI phishing is undetectable to humans.** Studies show humans correctly identify AI-generated phishing emails only **46%** of the time — a coin flip.
- **CEO voice-fraud wire transfers** are draining enterprise budgets — the Arup case lost **$25M** on a single deepfake video call.
- **The elderly, non-tech users, and small businesses** are hit hardest and have the fewest tools.

The scammers have AI. The victims do not. **Aegis AI closes that gap.**

### Target users
- **Everyday people & families** — anyone receiving suspicious texts, emails, screenshots, or calls (especially elders).
- **Small & medium businesses** — finance, HR, and support teams, the usual CEO-fraud / invoice-fraud targets.
- **Platform integrators** — email providers, telcos, banks, chat apps, and bots embedding Aegis via a single webhook.

---

## ✅ Solution — Six AI Shields

| # | Shield | What it does |
|---|---|---|
| 1 | **Message Scanner** | Paste any SMS, email, DM, or chat. 0–100 threat score, scam category, red flags, urgency tactics, plain-English recommendations. |
| 2 | **URL / Phishing Check** | Detects typosquatting (`paypa1.com`), look-alike domains, suspicious TLDs, shortened phishing. Suggests the real safe URL. |
| 3 | **Voice Call Analyzer** | Paste a call transcript — flags grandparent, IRS, tech-support, and voice-clone scams with a deepfake-voice likelihood score. |
| 4 | **🆕 Screenshot Scanner (Gemini Vision)** | Upload a screenshot of a suspicious message, email, website, or notification. Gemini reads the text + flags visual scam signals. |
| 5 | **🆕 Voice Recording Analyzer** | Record audio right in your browser. Gemini transcribes it, scores deepfake voice likelihood, and flags scam tactics. |
| 6 | **AI-Text Detector** | Spots content generated by ChatGPT / Claude / Gemini and estimates whether it's being used maliciously. |

**Plus:**
- **🆕 Live Threat Feed** — real-time, anonymized view of what Aegis is catching across the network. Updates every 4 seconds.
- **🆕 Public Integration API** — one webhook (`/api/webhook/scan`), copy-paste snippets for cURL / JavaScript / Python / any HTTP client.
- **🆕 Chrome Extension** — right-click any text or link on any webpage → Aegis scans it and shows a desktop verdict notification.
- **Scam Playbook Library** — 8 curated real-world scams with examples, red flags, and family-safe actions.

### Components used
- **Frontend:** React 18 + Vite, framer-motion for micro-animations, lucide-react icons, custom CSS design system (orange / off-white, bento grid, phone mockup).
- **Backend:** FastAPI (Python 3.10+), Pydantic v2 for validation, `google-genai` SDK, Uvicorn ASGI server, in-memory ring buffer for the live feed.
- **AI:** Google **Gemini 2.0 Flash Experimental** — multimodal (text + image + audio), structured JSON output via `response_mime_type`.
- **Chrome Extension:** Manifest V3, context menu + popup, desktop notifications.
- **Resilience:** Graceful heuristic fallback when `GEMINI_API_KEY` isn't set — demo always runs.

### Key endpoints

| Method | Path | Body | Purpose |
|---|---|---|---|
| `POST` | `/api/analyze/message` | `{ message }` | Scam / phishing analysis |
| `POST` | `/api/analyze/url` | `{ url }` | URL phishing / typosquatting detection |
| `POST` | `/api/analyze/call` | `{ transcript }` | Voice-call scam + deepfake-voice score |
| `POST` | `/api/analyze/deepfake-text` | `{ text }` | AI-generated text detector |
| `POST` | `/api/analyze/image` | `multipart file` | **🆕** Screenshot OCR + scam detection (vision) |
| `POST` | `/api/analyze/audio` | `multipart file` | **🆕** Voice transcription + deepfake detection |
| `POST` | `/api/webhook/scan` | `{ content, kind }` | **🆕** Public integration endpoint for 3rd parties |
| `GET`  | `/api/feed` | — | **🆕** Live anonymized stream of recent scans |
| `GET`  | `/api/stats` | — | Scan counts, threats blocked, fun facts |
| `GET`  | `/api/scam-library` | — | Curated scam encyclopedia |

## 🌍 Real-World Impact

- **Protects the elderly** — the most common voice-clone scam target. Family members can forward a suspicious message or screenshot to Aegis and get a plain-English verdict in 2 seconds.
- **Protects small businesses** — a finance clerk can paste a wire-transfer email into Aegis before sending $85K.
- **Protects everyone with a phone** — the UI is deliberately simple: paste or upload → see verdict → read what to do.
- **Open source** — anyone can self-host; messaging apps, banks, and telcos can embed the webhook API for free.
- **Educational** — the Scam Library teaches patterns, not just alerts, so users build durable instincts.
- **Shareable** — one-tap share lets a tech-savvy child send Aegis's verdict + explanation to a parent instantly.
- **Multi-channel coverage** — browser extension catches scams in real time while browsing; webhook API protects email/SMS/chat upstream.

## 🚀 Quick start

### 1. Backend (FastAPI + Gemini)

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1          # Windows
# source .venv/bin/activate         # macOS / Linux

pip install -r requirements.txt

copy .env.example .env              # Windows
# cp .env.example .env              # macOS / Linux

# Edit .env, set GEMINI_API_KEY (free at https://aistudio.google.com/apikey)

python main.py                      # starts on http://localhost:8010
```

### 2. Frontend (React + Vite)

```powershell
cd frontend
npm install
npm run dev                         # starts on http://localhost:5173 (or next free port)
```

### 3. Chrome Extension (optional)

```
chrome://extensions → Developer mode on → Load unpacked → select extension/
```

Right-click any text / link → **Aegis AI → Scan this for scams**.
